These PCBs are non-functional electrically and are purely silkscreen art. The original intention was a small, user-programmable LED matrix, but with limited time, I put the club's allocated budget toward printing tokens instead — a thank-you keepsake for judges attending the event, plus three additional boards for 1st-, 2nd-, and 3rd-place winners, each paired with a trophy. The PCBs slot neatly into the trophy base, making a nice set piece.

## ✨ Features

- 🎨 Purely silkscreen art — no functional circuitry
- 🏆 Designed to slot into the trophy base as a set piece
- QR code that links to Club Link Tree
- 🥇🥈🥉 Separate boards made for 1st, 2nd, and 3rd place winners
- 🙏 Judge tokens as a thank-you keepsake

## 🧩 What was made

| Item | Qty | Purpose |
|---|---|---|
| Judge tokens | 5 | Thank-you keepsake for attending judges |
| 1st place board | 5 | Paired with trophy |
| 2nd place board | 5 | Paired with trophy |
| 3rd place board | 5 | Paired with trophy |

## 🎯 Why this project

- Originally planned as a small, user-programmable LED matrix
- Time constraints meant pivoting to a silkscreen-only design instead
- Repurposed the club's allocated budget into a physical keepsake for the event
- Wanted the boards to double as a functional part of the trophy, not just a giveaway
